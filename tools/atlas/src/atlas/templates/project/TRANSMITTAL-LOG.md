# Transmittal Log - {{project_name}}

Every package of documents sent out of the studio, one row per transmittal. Log the row
when the package is sent, not when it is drafted. The package itself - cover sheet plus
the files as sent - goes in `YYMMDD_Transmittal-T-NNN/` beside this log.

**Rules**

- Numbers run T-001, T-002 ... and are never reused.
- One row per package. List every document in the package with its revision.
- Fill in Ack'd when the recipient confirms receipt. Chase anything unacknowledged
  that the next action depends on.
