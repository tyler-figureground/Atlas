# Where does it go? - {{project_name}}

Everything sent to or received from someone outside the studio lives in this folder,
under **who** it is with. Find the row, file it, done. If no row fits, ask Tyler before
making a new folder.

| I have... | It goes in |
|---|---|
| An email, letter or file from or to the client | `Client/In` or `Client/Out` |
| The same, with an owner who is **not** the client | `Owner/In` or `Owner/Out` (create `Owner` only then) |
| City or county requirements, checklists, pre-app notes | `AHJ/01 Requirements & Pre-Application` |
| A permit application form, owner authorisation, fee receipt | `AHJ/02 Applications & Forms` |
| The set we filed with the city or county | `AHJ/03 Submissions/R<n>_YYMMDD` (one folder per round) |
| Plan-check comments, and our response letter | `AHJ/04 Comments & Responses/R<n>_YYMMDD` (same round number as the submission it answers) |
| Any other email or letter with an agency | `AHJ/05 Letters & Emails` |
| An issued permit, stamped set, inspection record, final | `AHJ/06 Permits & Inspections` |
| Anything with an engineer, surveyor or other consultant | `Consultants/<Discipline>/In` or `Out` |
| Bids, RFIs, submittals, change orders, sketches with the contractor | `Contractor/<that folder>` |
| Anything else with the contractor | `Contractor/In` or `Out` |
| Quotes, cut sheets, orders with a vendor or supplier | `Vendors/In` or `Out` |
| A draft not sent yet | `_Outbox` - move it to the party's `Out` the day it is sent |

**Naming.** Inside every `In` / `Out`, one folder per exchange: `YYMMDD_<Description>`, for
example `261022_Henrybuilt_Kitchen shop drawings`. Files stay exactly as sent or received.
A firm, agency or vendor name goes in the folder name, never as its own folder level.

**Every application** to an agency gets a row in `AHJ/AHJ-REGISTER.md`. **Every package**
sent out gets a row in `TRANSMITTAL-LOG.md` and a `YYMMDD_T-NNN_<Description>` folder in that
party's `Out`.

**Not here.** Proposals, contracts and invoices: `10 Legal`. Meeting minutes: `11 Meetings`.
What the code says: `06 Research & Existing Conditions/Code`. Field reports and punch lists:
`12 Construction Administration`.
