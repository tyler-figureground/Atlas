# AHJ register - {{project_name}}

Every application to every authority having jurisdiction (building, planning, fire, health,
air district, public works, utilities). One row per application. Update the row whenever its
status changes; the files sit in the stage folders beside this register.

| Stage folder | What goes in it |
|---|---|
| `01 Requirements & Pre-Application` | submittal checklists, agency requirements, pre-application notes, blank forms |
| `02 Applications & Forms` | completed forms, owner authorisations, fee receipts |
| `03 Submissions` | exactly what was filed, one `R<n>_YYMMDD` folder per round, agency in the file name |
| `04 Comments & Responses` | plan-check comments in, response letter and matrix out, in the `R<n>_YYMMDD` folder of the round they answer |
| `05 Letters & Emails` | letters, emails, records requests to and from agencies |
| `06 Permits & Inspections` | issued permits, approved stamped sets, inspection records, final / CofO |

What the code *says* stays in `06 Research & Existing Conditions/Code`. What *this agency
asked for, and what we sent*, lives here.

|---|---|---|---|---|---|---|---|

**Status:** researching - preparing - submitted - in review - comments - resubmitted -
approved - issued - inspections - finaled - withdrawn

Start the Status cell with one of these words, then the date it changed
(`comments - 2026-10-01 intake review`). Round is the number of the latest `R<n>` folder.
`atlas permits` and the daily digest read this table to say whose move each application
is and for how long.
