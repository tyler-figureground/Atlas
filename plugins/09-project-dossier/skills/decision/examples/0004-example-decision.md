# 0004 - Sprinkler the loft conversion with NFPA 13R, not NFPA 13

- **Status:** decided
- **Date:** 2026-04-09
- **Deciders:** Mara Ellison (client), with the architect

## Context

Fable Street Lofts converts a four-story tin works to six residential units. The code analysis (06 Research & Existing Conditions/Code/fable-street-lofts-code-analysis.md) showed either NFPA 13 or 13R could satisfy the trigger, at very different cost. The client needed the call before the MEP set went to pricing.

## Options considered

1. **NFPA 13 throughout** - full commercial-grade system; highest cost, no design constraints
2. **NFPA 13R** - residential system; roughly half the cost, limits future conversion of the ground floor to assembly use
3. **NFPA 13D** - rejected early; not permitted for a six-unit building

## Decision

NFPA 13R. The building stays residential for the foreseeable hold, and the cost difference funds the required egress-stair rebuild.

## Consequences

- MEP set prices against 13R; drawings note the system on the code sheet
- Any future ground-floor assembly use re-triggers a full NFPA 13 review
- Code analysis section 7 updated to cite the 13R path
